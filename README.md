# Diabetes Risk Factor Analysis

A beginner data science project exploring the **Pima Indians Diabetes Dataset** — a public dataset of 768 patients — to identify which health measurements are most associated with a diabetes diagnosis.

## What this project does
- Loads and cleans the dataset (fixes a common real-world issue: missing values recorded as `0`)
- Compares average glucose levels between diabetic and non-diabetic patients
- Calculates which health measurements correlate most strongly with diabetes
- Visualizes findings with a box plot and a correlation heatmap

## Key finding
Glucose level showed the strongest relationship with diabetes diagnosis, followed by BMI and age.

## Tools used
Python, pandas, NumPy, matplotlib, seaborn (via Google Colab)

## Files
- `diabetes_analysis.ipynb` — the full notebook with code, charts, and write-up
- `diabetes.csv` — the dataset
